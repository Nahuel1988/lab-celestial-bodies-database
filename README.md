# lab-celestial-bodies-database

Base de datos PostgreSQL para el proyecto **Celestial Bodies Database** de freeCodeCamp.

## Archivos
- `universe.sql`: esquema completo y datos iniciales de la base `universe`.

## Uso
1. Iniciar un servidor PostgreSQL local.
2. Ejecutar:
   ```bash
   psql -U postgres -f universe.sql
   ```
